## State inventory (gaps only)

- **Error**: delete workout (History list, detail) and Save as Template fail with an OK-only alert (P2 above). The generic
  `SaveErrors` "Could Not Save" is OK-only by design (no closure to retry); acceptable once its message names the recovery.
- **Loading chrome**: TemplatePreview's chrome is outside the loaded branch, but it has no title to show (P1). The
  ExerciseDetail toolbar sits in `content(info)`, which needs only the synchronous store lookup, so there is no pop-in.
- **First run / empty**: Workout's empty state offers only New Template; Empty Workout sits one level down in Add (see the
  taste section below).
- Not checked this round (needs a sim): overflow at 40-character names and accessibility-extra-large truncation, dark mode,
  the Disabled states rendered.

## Taste calls for Eric (one batched question)

1. **Alert and dialog title case.** The web's sentence-case copy was kept verbatim ("Discard workout?", "Delete workout?",
   "Discard changes?", "Nothing logged yet", "Workout in progress", "Add a working weight first", "Could not delete the
   workout.") next to native title case ("Finish Workout?", "Rename Workout", "Could Not Finish", "Update Template?",
   "Turn Off Apple Fitness?"). The HIG uses title-style capitalisation for alert titles. Convert all of them to title case
   (one worker, copy only)? Files: `FinishFlow.swift:107,149`, `HistoryView.swift:195,206`, `WorkoutDetailView.swift:94,121,570`,
   `PastWorkoutEditor.swift:95`, `TemplateEditor.swift:85`, `StartWorkoutFlow.swift:105`, `BlockActionSheets.swift:113`,
   `CustomExerciseForm.swift:220`.
2. **Exercise detail title (JC29).** Set the inline title to the exercise name (it only shows on the open display, next to the
   in-content name), or keep it empty?
3. **Template preview title.** With an inline title added, keep the in-content `.title` name under it (Fitness style), or drop
   the in-content one?
4. **Workout empty state.** Add "Empty Workout" as a second action under New Template, so the first launch can start
   lifting without opening the Add menu?
