## Checked and sound

- e1RM: Epley/Brzycki clamp reps at 12, low-confidence flag above 12, Brzycki never divides by 0; confident beats low-confidence everywhere (`betterE1RM`, `e1rmBeats`, `RecordTracker.offer`).
- Units: `toKg`/`convert` use the exact 0.45359237; `round05` only at display; comparisons in kg with 1e-6 tolerance; Previous and plan values convert into the row's unit (`convertedWeight`), same-unit values pass through unrounded.
- Volume excludes warm-ups and unchecked (`countedSets`) and assisted types; Finish sums kg then rounds once.
- PRs: history strictly before the session, same-workout rows merged before judging, repsAtWeight suppressed for the heaviest-PR weight; equal is not a PR (strict `compareKg > 0`). Assisted inverts heaviest and reps domination.
- Previous: newest finished workout with a completed set, nth same-exercise row mapped to nth row with fallback, warm-ups and working sets indexed separately (`indexByKind`), stable tie-break on equal `startedAt`.
- Warm-up ramp: bar step only below working weight, steps strictly increasing and below working weight; completed warm-ups kept, unchecked replaced, rest owned by removed sets cancelled; custom bar converted on unit switch in both engine and draft.
- Template update: structure vs values diff compares kinds/counts/normalized superset groups; unit switch converts uncopied weights (E-05 fix present).
- Week boundaries: Monday-first with ISO `minimumDaysInFirstWeek = 4`, intervals half-open, device time zone via the injected calendar.
